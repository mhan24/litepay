## 兼容性和验证边界

- 不保留旧配置裁剪、旧 Token 迁移、`trade_no` 状态查询参数、未使用的金额工具或兼容字段。公开订单号格式、金额保留行为、金额匹配精度、可接受回调地址、下单参数范围和代理信任配置均有变更。取消后的档位会继续占用到原监听窗口结束，高并发容量相应降低。
- 新数据库字段记录订单选择时间和精度。旧版本尚未结束、没有这些快照的开发订单应作废并重新创建；本次没有操作远端数据库或清空现有业务数据。
- trusted_proxies 默认空。当前生产配置只信任 Caddy 固定地址 `172.18.0.2/32`；Caddy 重建后若 IP 改变，必须同步更新，不能信任整个 Docker 子网。
- PBKDF2 派生规则与旧版 SHA-256 不同，部署后所有已登录后台会话立即失效，需要重新登录。这是允许的破坏性安全变更。
- 回调竞争保护按单实例运行设计，不支持多个独立进程共享同一数据库共同处理订单。
- 分页过密、超过请求预算或同一时间戳容量饱和时会报错，避免把不完整读取当作完整成功；需要通过后台状态及时处理此类错误。
- 本次进行了源码审计、本地测试、竞态检测、依赖扫描、交叉构建和生产部署后只读核验。未进行真实 Binance / OKX 账户付款测试；真实商户通知与完整端到端收款仍需单独验证。
- 当前目录未包含 Git 元数据，修复保存在工作区文件中。本报告记录本次检查的范围与结果，不构成所有未来输入和运行条件下均无缺陷的保证。
