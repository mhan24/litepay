> **状态：未执行任何真实资金转移，真实资金闭环未验收。**
> 本文只区分「离线与只读已验证」和「必须由用户真实转账后才能判断」两类结论。
> 清单本身不构成任何通过结论；第 4、5 节的所有判定项在执行前一律标记为**未验证**。

金额口径：创建订单限制原始金额在 `[0.0001, 1000000)`；本版本起，选择付款方式时分配的
应付金额（`PayUnits`）也被强制约束在同一区间（向上对齐、档位递增、重选三条路径都覆盖），
没有合法档位时直接拒绝选择，不截断、不调低、不四舍五入，也不留下档位占用。

## 2. 只有真实资金才能判断（当前全部**未验证**）

- 真实 Binance Pay / OKX 站内转账记录在网关只读查询里的可见时间与字段形态。
- 真实 OKX 内部转账是否出现 `state=1` → `state=2` 的中间态，以及网关的待确认证据能否在补查中正确升级为已支付。
- 商城真实实例（dujiao-next）对回调的验签、`status=2` 处理与**交付幂等**（模拟商城只证明算法一致，不证明真实数据库与发货链路）。
- 交易所自身最小转账限额 vs 配置的最小应付金额（例如 USDT 站内转账可能不接受 0.01）。
- 真实 `notify_url` 的公网可达性、TLS 与超时行为。
- 真实延迟下的付款窗口（订单有效期 + 宽限期）是否足够。

## 3. 前置准备（不涉及资金）

1. 后台 `/admin/settings`：配置只读 API 凭据（已配置）、Binance / OKX 收款 UID、币种、应付精度（默认 2 位）、最小应付金额、金额步长与最大调整次数。
2. 后台 `/admin/integration`：读取 BEpusdt 接入地址与 Token，填入商城支付网关配置；`reselect` 开关按需。
3. 建议本次验收金额 **≥ 1 USDT**（规避交易所最小转账限额），并保证订单金额 < 1000000 USD。
4. 商城订单金额建议取 `10.00` 这类整额，便于人工核对“商城金额 / 应付金额 / 实际到账”三者关系。
5. 明确本次验收的**唯一付款方账户**：与收款 UID 不同、且为已实名可转 USDT 的账户。

## 4. Binance 最小验收步骤（需要用户自行决定是否发起小额转账）

| 步 | 动作 | 记录 / 判定标准 |
| --- | --- | --- |
| 1 | 商城创建一笔测试订单，走 LitePay 网关 | 商城订单号、下单金额 |
| 2 | 收银台选择 Binance + USDT | 页面进入“确认付款信息”，显示应付金额与收款 UID |
| 3 | 记录**网关交易号**及**精确应付金额** | `/admin/orders/{trade_no}` 的「网关订单」「应付」两行；含全部小数位，逐位比对无四舍五入 |
| 4 | 由用户自行决定是否发起小额站内转账（Binance Pay → 收款 UID，金额逐位照抄） | 转账流水号 / 交易编号（App 账单里可复制的数字订单号，或 `transactionId`） |
| 5 | 用真实交易记录核对扫描与到账 | 等待后台自动扫描。期望：订单 `READY → PAID`，`实际核销` 有到账时间 |
| 6 | 验证订单只核销一次 | 后台「已认领资金事件」恒为 1 条；再等几轮自动扫描后仍为 1 条，状态不反复 |
| 7 | 验证 BEpusdt 回调被商城验签并确认 | 后台「商户通知」显示尝试次数与「商户确认于 …」；商城侧订单转已支付。若多次尝试后仍未确认，记录每次 `HTTP 状态码 / error` |
| 8 | 验证商城最终交付状态，排除重复交付 | 商城订单为已完成/已发货且**仅一次**；再次触发回调后商城不发生第二次交付 |

**通过标准**：第 3 步金额与第 4 步实际转账完全一致；第 5 步订单恰好一次进入 `PAID`；
第 6、8 步无任何重复核销或重复交付；第 7 步商城明确确认（2xx + `success`/`ok`）。

## 6. 失败与停止条件

- 第 5 步长时间（超过订单有效期 + 宽限期）未自动核销：**不要重复付款**，保留转账截图与编号；把 `provider / depId 或 transactionId / 金额 / 时间` 交给人工在交易所与商城核对。
- 第 7 步回调始终未获确认：记录 LitePay 后台每次尝试的 HTTP 状态码与错误，以及商城侧日志；商城未确认前商城不会交付。
- 出现金额不一致（到账金额与应付金额不同）：网关按设计不会核销，保留证据；这一笔需要人工在商城侧处理，不得手工改金额重试。
- 单一凭证只做一次小额验收；验收结论仅对该账户、该币种、该时间段有效。
