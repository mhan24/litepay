收款平台与币种

独角数卡通过 JSON 调用 create-order，网关返回收银台地址 payment_url。付款人先选择 Binance 或 OKX，再选择 USDT 或 USDC， 最后按页面显示的精确金额发起站内转账。

收款平台支持币种到账确认方式
Binance USDT / USDC 通过只读 API 查询站内转账，按 UID、币种和精确金额确认订单
OKX USDT / USDC 展示收款 UID，通过只读 API 查询站内转账；链上充值不会自动确认

支付结果通知

网关发送到你的商城

下单时传入的 notify_url 是结果通知地址，独角数卡会自动拼接。 网关使用 POST JSON 发送 BEpusdt 标准通知。支付成功通知要求 HTTP 2xx，且响应正文精确为 success 或 ok（不区分大小写）； 过期通知按官方协议要求 HTTP 2xx，并会把明确的 fail 正文判为失败。 部分 Dujiao Next 版本会拒绝 status=3，此时网关只能结束本地监听， 无法强制修改商户订单状态。失败时会按配置的间隔重试，最终结果以通知记录为准。

独角数卡配置步骤

  1. 进入独角数卡后台，打开“支付配置”，新增支付渠道并选择“BEpusdt”。
  2. 网关地址填写 {{.BaseURL}}，只填写域名，不要附加接口路径。
  3. 粘贴上方 API Token。Token 由系统随机生成，只能通过“生成新 Token”轮换。结算法币固定为 USD，USDT / USDC 按 1:1 计。
  4. 订单模式选择“收银台”，网关会调用 create-order。币种限制可留空，或填写 {{range $i, $c := .Currencies}}{{if $i}},{{end}}{{$c}}{{end}}。
  5. 付款人依次选择 Binance 或 OKX、USDT 或 USDC，然后按页面金额发起站内转账。
  6. 同一商户订单号下未过期的待支付订单会复用，且不会延长原有效期；已过期、已取消或被替换的旧订单会静默退役。
  7. 支付成功后，网关发送 status=2 的结果通知。独角数卡返回 success 后即完成发货流程。
  8. 独角数卡主动取消订单时会调用 /api/v1/order/cancel-transaction。网关随即停止确认到账，不再发送过期通知。
  9. 网关自动过期或后台提前结束时，会在支付窗口和宽限期结束后发送 status=3。若 Dujiao Next 返回 fail，订单会显示通知失败；网关不能伪造支付成功回调，也不会承诺强制关闭商户订单。
